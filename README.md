# AIXUS Web

Sitio estático de AIXUS, preparado para Cloudflare Pages.

## Configuración de Cloudflare Pages

- Comando de compilación: `npm run build`
- Directorio de salida: `out`
- Versión de Node.js: `22`

Rutas publicadas:

- `/`
- `/neo`
- `/neo/pagina-web`

Los formularios de consulta funcionan en el navegador mediante EmailJS.
